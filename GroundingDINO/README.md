# GroundingDINO

Run the notebook from the repository root with the standard executor:

```bash
uv run python tools/execute_notebooks.py --model GroundingDINO --allow-large-downloads
```

To build the local notebook environment for interactive use:

```bash
cd GroundingDINO
uv sync
```

Then select `GroundingDINO/.venv/bin/python` as the notebook kernel.
