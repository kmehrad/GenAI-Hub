# BERT-deepset

Run the notebook from the repository root with the standard executor:

```bash
uv run python tools/execute_notebooks.py --model BERT-deepset --allow-large-downloads
```

To build the local notebook environment for interactive use:

```bash
cd BERT-deepset
uv sync
```

Then select `BERT-deepset/.venv/bin/python` as the notebook kernel.
